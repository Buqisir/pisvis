## 1. 先做样板，再确立风格

最多比较两套候选：A“轻质感科学插画”，主体可有适度明暗和层次；B“精密清爽线描”，重视线型、比例和留白。
候选共享真实数据与布局，以便比较的是表达而非题目差异。两者都不能退化成彩色装饰背景加默认黑线。
“卡通感”“玻璃感”或大面积模糊不是默许特色；维护者明确要求探索的方向（如 C 的辉光）可作为显式候选实现，仍待批准。

交付应是浏览器里真正渲染的组件样板与可交互场景，附截图。截图只是证据，不是组件实现。
批准记录包含日期、样板路径/提交、选定方案、仍需调整项；未得到反馈时标为候选，
可以继续不依赖风格定稿的数学和数据开发，不得自行写成“用户已批准”。

## 2. 统一 token，而不是逐题调色

| 类别 | 应统一的规则 |
| --- | --- |
| 语义颜色 | 对象、输入向量、派生结果、辅助分量、选择、错误与焦点；同一角色跨图一致 |
| 图形比例 | 主/辅助线宽、箭头头长和头宽、端点尺寸、圆角、虚线间隔 |
| 文字 | 中文说明、变量、公式、数值、单位的字号层级和间距；不以任意手写字体充当全部风格 |
| 空间 | 留白、标签间距、图例、标注锚点与安全边界 |
| 材质 | 主体有限渐变/纹理，辅助表达保持克制；不影响几何边界 |
| 状态 | 默认、悬停、选中、拖动、不可编辑、错误与键盘焦点 |
| 动效 | 进入、强调、分步显示、取消和重置；减少动效时仍完整可用 |

token 用项目定义的普通数据表达；浏览器 CSS 变量是适配，不是模型真相。
主题 ID/版本和允许的局部覆盖应可记录。更换主题不得更换单位、数值、连接关系或题设。
命名用语义而不是“蓝色箭头1”，但不强制所有不同物理量必须各占一种颜色；图例与符号共同表达含义。

## 3. 图形必须诚实

显示空间和物理空间分开。空间图默认等比例变换，避免把不同方向拉伸后仍声称角度/长度按比例。
力、速度、位移有各自显示比例；同一组需要比较或合成的同量纲矢量采用一致比例。
若使用示意而非按比例表达，需明确标识；不能让用户从装饰长度误读量值。

零向量不伪造方向。分量和合量可同时教学展示，但不能被当作额外的真实力重复计入。
物块的材质不遮住接触边；线的重叠不等于电路连接；运动轨迹与时间函数图像不混用。
这些是工程表达约束，具体学科场景仍须核对正文与适用条件。

标签优先使用可预测的候选锚点和人工偏移。拥挤时给出提示/调整入口，不暗中挪动物理对象。
自动避让是后续可选实验，不能成为第一张图的前置条件。

## 4. 现代原生能力与增强依赖

SVG 提供基本形状与渐变等表达能力；CSS Color 4 定义 OKLCH 等颜色表达；Pointer Events 统一指针输入。
可用这些能力建设自己的视觉系统，规范存在不等于目标浏览器的每一项实现均已验证。
来源：[SVG 2](https://www.w3.org/TR/SVG2/)、[CSS Color 4](https://www.w3.org/TR/css-color-4/)、
[Pointer Events](https://www.w3.org/TR/pointerevents3/)。

项目约定：OKLCH 给出 sRGB 降级；无滤镜时仍能读懂；普通交互不以 WebGPU 为前提。
简单反馈可用 CSS/[Web Animations](https://www.w3.org/TR/web-animations-1/)，需要有限教学序列时使用 Motion 适配。
它们都不计算物理轨迹。具体引入安排见 [依赖决策](DEPENDENCIES.md)。

## 5. 交互、可访问性和动效

拖动之外保留数字输入、键盘路径和可见焦点；不要把颜色作为唯一判别方式。
减少动效模式消除装饰性移动，不丢失教学步骤信息；物理播放始终由用户主动控制。
高频读数可显示，但不要每帧向屏幕阅读器播报长句。错误提示应说明可修正的原因。

物理时间、讲解步骤和 UI 动画分别管理。Motion 不得和模型渲染同时写同一 transform。
暂停/重置/卸载要取消旧动画；新一次讲解不能被旧序列回调改回去。

多实例中的 SVG ID、渐变、clipPath、aria 引用和样式作用域必须隔离。
字体从合法包资产或系统回退使用，不复制系统字体、教材字体或未经授权素材到仓库；
测试记录浏览器和字体环境，待布局稳定后截图。KaTeX 公式优先置于 HTML 面板，
不将公式输出冒称为已支持纯 SVG/PDF 打印。

## 6. 样板验收

用默认值、零/反向/极短向量、参数边界、长中文标签和拥挤组合检查。
至少两个容器尺寸，查看正常与灰度、键盘焦点和减少动效模式；SVG 缩放后标签和手柄仍可用。
数值断言、交互测试、截图回归和维护者审美反馈分开记录，任一项不能代替其他项。

第一批样板继承到第二个场景，才算视觉可复用。不得每新增题型就复制整份 CSS。
性能记录实际设备、浏览器、场景规模、首次显示和连续更新耗时；先测再设预算，
不以库官网的跑分保证本项目“永远 60 FPS”。
