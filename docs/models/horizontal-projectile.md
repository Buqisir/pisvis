## 2. 原文关系与坐标约定（来源事实）

书中坐标：抛出点为原点 O，x 水平向右，**y 竖直向下为正**（随下落增长）。

速度（知识点 1，图 5-4-1）：
- 水平分速度 v_x = v_0；竖直分速度 v_y = gt
- 合速度 v = √(v_x²+v_y²)；方向 tan α = v_y/v_x = gt/v_0，α 为与水平方向夹角
- 速度改变量 Δv = gΔt，恒竖直向下；α 随 t 增大但不到 90°

位移与轨迹（知识点 2、4）：
- 水平分位移 x = v_0·t；竖直分位移 y = ½·g·t²
- 合位移 s = √(x²+y²)；方向 tan θ = y/x = gt/(2v_0)，θ 为与水平方向夹角
- 轨迹方程 y = g·x²/(2v_0²)（抛物线，y 向下为正）

有用结论（能力点 1）：
- 运动时间 t = √(2h/g)，只由下落高度决定，与 v_0 无关
- 水平距离 x = v_0·√(2h/g)
- 落地速率 v_t = √(v_0² + 2gh)

书中明确警示（可做教学点）：速度偏向角 α 与位移偏向角 θ 含义不同，且恒有
tan α = 2·tan θ（由上两式直接推出），不要把两者混用。

## 3. 本项目坐标转换（项目决定，非来源）

项目坐标：x 向右、y 向上，地面 y=0，抛出点 (0,h)，初速度 (u,0)，
g 为向下重力加速度的正大小。

- 换算：y_书 = h − y_项目；v_y_项目 = −v_y_书。
- 模型关系，时间域 t ∈ [0,T]：
  - x(t) = u·t；y(t) = h − g·t²/2
  - v_x = u；v_y = −g·t
  - T = √(2h/g)；R = u·T；落地速率 |v(T)| = √(u² + 2gh)，与书 §2 一致
- 停止条件：t = T 时落地终止，不计算穿过地面的运动。
- 「速度反向延长线过水平位移中点」在项目坐标同样成立并可做不变量测试：
  t 时刻位置 P=(ut, h−gt²/2)、速度 (u,−gt)，反向延长线交过抛出点的水平线于
  x = ut/2 = x_P/2（推导见书中例 3 结论 OA = x₀/2）。

## 4. 参数、退化与项目新增（项目决定）

- 模型接受：h > 0、g > 0、u ≥ 0，全部有限并做溢出检查。
- 编辑器范围（产品范围，非物理约束）：h ∈ (0,100] m、g ∈ [1,20] m/s²、u ∈ [0,40] m/s。
- u = 0 为明确标注的自由落体退化：轨迹用 t 参数化，禁止调用除以 u 的轨迹式
  y = (g/2u²)·x²，不给零水平速度伪造方向。
- 书中「一般的抛体运动」（知识点 3，斜抛）本轮不做。
- 项目新增（非来源内容）：同一快照驱动情境图/小球轨迹/速度与分量箭头/公式读数/
  v_x, v_y–t 图；时间可播放、暂停、拖滑块，落地精确停于 T；原题/探索模式分离；
  空间图等比例，速度箭头用独立但共用的显示比例。

## 5. 独立测试数据（验收用）

- **Issue 约定主例**：h=20 m、u=10 m/s、g=10 m/s² → T=2 s、R=20 m；
  t=0 位置 (0,20)、速度 (10,0)；t=1 位置 (10,15)、速度 (10,−10)、速率 √200；
  t=2 位置 (20,0)、速度 (10,−20)。
- **例题 1**（书页 22，2020·荆州期末）：g=10、v_0=10 m/s；t=1 s 时 tan α=1（α=45°），
  落地时 β=60° → |v|=20 m/s、v_y=10√3 ≈ 17.32 m/s、h=v_y²/(2g)=15 m。
  对应 T=√3 ≈ 1.732 s、R=10√3 ≈ 17.32 m。
- **例题 2**（书页 22，2020·九江模拟）：v_0=6 m/s、水平飞行 d=3.6 m 后嵌入竖直墙，
  嵌入时速度方向与墙成 45° → v_y=v_0·cot45°=6 m/s，t=0.6 s，竖直位移 y=1.8 m，
  合位移 s=√(3.6²+1.8²)=9√5/5 ≈ 4.02 m。
- **例 3 不变量**（书页 23，2020·海淀模拟）：轨迹上任一点 P(x₀,y₀)，速度反向延长线
  交抛出点水平线于 A，OA = x₀/2。任取 t、u、g、h 都应满足（见 §3 推导）。
- 另需覆盖：不同 u/h/g 组合、u=0、非法输入、溢出、t=T 边界不穿透；
  主题/布局变化不影响数值；序列化往返与实例隔离。
