# 小步路线：每一步都能验收

这里是方向，不是同时开工的任务列表。具体 Spec 放 GitHub Issue，以下后续项均未实现。

## 初始化种子（本次）

自己的向量、坐标换算、箭头几何、纯 SVG 输出、参数实验页源码、基础测试与 Agent 交接文档。
核心类型检查与 25 个测试已通过；完整依赖安装和浏览器链路还不是已完成项。

## 首轮 M1：工程复现 + 可操作的箭头

先在联网本地环境复核精确依赖版本、提交真实锁文件，完成干净安装与演示构建，再配置 CI。
接着让同一个箭头的两个端点可拖动；正确处理 viewBox、CSS 缩放、滚动、指针捕获/取消与重置。
保留数值输入作为键盘操作方式；失败有可读提示。用真实浏览器测试验证，而不只截图。

验收：换个机器能复现；拖动和数值输入使用同一状态；各种缩放下不漂移；重合端点行为一致；
核心仍不依赖 DOM；不引入物理求解器或大框架。

## 第二轮 M2：少量图元 + 最小场景文档

增加线、圆/弧、文字与分组中实际用到的部分，先做两个小场景复用。
据此设计带版本、稳定 ID、运行时校验的纯数据文档，验证保存/读取/修改的往返一致性。
文档到图形单向派生；不把 DOM 当数据库。输入限额与错误结果和导入功能一同交付。

验收：不是每个例子复制一套几何代码；非法文档不能悄悄画成另一张图；重复加载不改语义。

## 第三轮 M3：第一个明确假设的物理场景

候选是固定、光滑斜面上的物块。先核对参考正文并让维护者确认教学目标，再写独立的物理模型。
受力、分解、标注与图形布局分开；不添加未成立的力；参数和结果有数值测试。

验收：说明模型为什么适用、何时不适用；改变图形排版不改变物理结果；改变参数有可核对结果。

## 后续按真实需求选择

从抛体/运动图像、振动/波、电场/磁场、电路/光学、热学/近代物理中选下一个小场景，
不设“全高中覆盖”的短期承诺。优先验证跨场景复用，再补大范围图元目录。

在真实消费者出现时再加 React 适配；在明确渲染压力或空间教学需求出现时再评估 Canvas/3D；
在真实公式排版、打印需求出现时再引入对应适配。当前不提前安装这些依赖。
