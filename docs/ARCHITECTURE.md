# 架构：小型自有内核 + 可替换能力 + 可复用题型

更新：2026-09-28（UTC+08）。把已实现结构与目标架构分开；新增层次不代表已有 API，也不是一次建完的目录清单。

## 1. 当前代码的真实边界

```text
src/math/vec2.ts          有限数值、向量运算
src/core/viewport.ts      世界与 SVG 逻辑像素坐标互换
src/primitives/arrow.ts   箭杆与三角箭头几何
src/render/svg.ts         纯 SVG 序列化，不访问 DOM
src/index.ts             公共导出
playground/              浏览器实验页源码
skills/                  Agent 使用约定
```

当前依赖方向：math 被 core/primitives 使用，render 消费几何，playground 使用库。
还没有场景/模板系统、Signals/Valibot 接入、物理模型、自动排版、时间轴或 Agent Tool 注册。
本次设计更新不修改这些实现或 package.json，初始化测试边界见 [HANDOFF](HANDOFF.md)。

## 2. 自研与借用

自研物理语义、模板、关系、绑定、教学步骤和视觉规则；可以继续研究基础数学，但不为证明原创而重写所有通用能力。
普通二维图保留 SVG 主线。实例响应、文档校验、公式排版和教学动效分别由经过验证的局部适配承担。
采用次序见 [DEPENDENCIES](DEPENDENCIES.md)，官方技术来源见 [TECH_RADAR](TECH_RADAR.md)。

当前纯数学/几何内核继续无 DOM、无网络、零第三方运行时依赖。整个项目不再将零运行时依赖作为目标。
后续借用复杂几何需具体收益和测试，不为换库而删除已验证的小算法。

## 3. 目标职责与数据流

| 职责 | 权威内容 | 允许借用 |
| --- | --- | --- |
| 文档与题目实例 | 条件、版本、目标、原题/探索模式、允许的覆盖 | Valibot 边界校验 |
| 模型 | 假设、单位、纯函数输入输出、停止条件 | 有理由的数值/几何辅助，不依赖 DOM |
| 实例控制 | 候选校验、原子更新、时间/步骤、生命周期 | Signals |
| 场景构建与绑定 | 对象/锚点、计算量到图形/图像/读数的联系 | 少量几何适配 |
| 视觉与显示 | token、布局、标签、SVG/HTML | KaTeX、Motion；GPU 后端仅后续实验 |
| Agent 使用层 | 发现真实能力、选择模板、提交有限命令 | Skill，不替代运行时校验 |

主链：文档/命令 → 校验后的输入 → 模型快照 → 场景、公式、函数图和读数。
主题与布局进入表现层，不反写模型。原题条件与探索参数分离；实例相互独立。
通用契约见 [REUSE_AND_BINDINGS](REUSE_AND_BINDINGS.md)。

先保持单包、可读模块和少量显式接口，不提前建插件总线、通用表达式引擎、约束 DSL 或依赖注入框架。
M2 用两种小数学模板验证关系；M3 才增加具体物理模型。模板注册到受审查代码，存档不携带可执行函数。

## 4. 坐标约定（保留现有行为）

世界 x 向右、y 向上。内部后续角度用弧度；教师可输入度但要显式转换。
Viewport.originPx 与 worldToScreen 的 screen 指 SVG viewBox 内逻辑像素，
不是 clientX/clientY，也不是设备物理像素。CSS 响应式缩放是另一个变换。

```text
svgX = originX + worldX * pixelsPerUnit
svgY = originY - worldY * pixelsPerUnit
```

M1 拖动先用 getScreenCTM 的逆变换将 client 坐标变为 SVG 用户坐标，再进入核心逆变换；
要检查矩阵缺失/不可逆，不能简单减页面偏移。当前比例必须为有限正数。

图形坐标没有默认物理单位。物理模型内部明确单位和参考系，显示比例独立；
不能把像素、图形长度当质量、力或真实位移。情境空间默认等比例，函数图坐标单独标刻度/单位。

当前渲染器先把端点转换为 SVG 逻辑像素，再生成箭头；因此头部不随世界缩放滑块放大，
但会随整个 SVG 的 CSS 缩放变化，不宣称始终固定为设备像素。
normalize 对零向量返回 null，重合端点产生 kind:'zero' 并显示点。
短箭头头长最多为总长 45%，头宽同比缩小；这是现有表示策略，不是物理定律。
有限输入计算溢出仍需显式失败；浮点容差按尺度和量纲设计，不用一个全局 epsilon 套所有模块。

## 5. 模型与表示不能互相冒充

物理模型说明适用假设、输入、输出、量纲与停止条件，保持可在 Node 独立测试。
不能因图中存在一个箭头就判定有一个力；力的分解和合成不重复加入真实外力。
电路的连线表示与电路求解、波的空间图与时间图、统计/量子示意与真实轨迹分别定义。

首个题型默认选水平抛出，模型范围和数值验收在 [M3 #4](https://github.com/Buqisir/pisvis/issues/4)。
原有光滑斜面保留为后续候选，需另核对接触、外力与法向加速度条件。
来源事实与项目新增交互分别记录，来源访问不到不能伪称已核验。

## 6. 数学约束、状态联动与动画

显式纯函数计算模型，Signals 管联动，不期待它自动反解或求解任意循环方程。
导入或编辑先在候选数据上校验并完整计算，成功后一次提交。batch 不等于失败回滚。
视图共用快照；旧的异步/动画回调不能覆盖新版本。布局优化若以后接入，只改变许可的表现变量。

物理时间不等于渲染帧率。解析模型以 t 求值；未来数值积分另外声明步长、误差和收敛/守恒检查。
Motion/原生动效负责讲解的出现和强调，不控制真实物体运动；二者不得竞争写同一属性。
暂停、重置、卸载、切后台和减少动效都有明确规则，资源按实例释放。

## 7. 安全、模块与导出

现有 SVG 输出只含固定标签/属性、数值校验、文字 XML 转义和非法 XML 字符拒绝。
不能扩展为执行任意上传 SVG/HTML、foreignObject、脚本、外部资源 URL 或公式 JavaScript 的入口。
KaTeX 输出走独立受控适配，不能为了公式放开普通标签的 HTML 注入。

数学根入口不加载 DOM、Motion、KaTeX 或 GPU 初始化代码；用实际导入和构建产物检查隔离。
公共文档和模板类型使用 pisvis 的普通数据，不泄漏 Signal、Pixi 节点或 GPUBuffer。
浏览器可访问性与文字输出独立保留，不能因未来换 Canvas 而丢键盘入口。

SVG 序列化不等于完整打印已实现。HTML 公式、字体、滤镜、分页和矢量导出都要独立验收。
本阶段不为未来第二个后端提前重写所有渲染代码。
